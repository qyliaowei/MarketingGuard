## 第二章 常用表达方式库（句式黑名单）

### 2.1 伪深刻句式（AI 生成的高发句式）
| 句式模板 | 示例 | 说明 |
|---|---|---|
| 不是 A，而是 B | 「穷人不是不努力，而是不会选择」 | 最典型的 AI 味金句结构，无信息量 |
| 越 X 的人，越 Y | 「越没本事的人，越爱面子」 | 伪规律，可无限套用 |
| 真正的 X，都 Y | 「真正的强者，都懂得沉默」 | 定义劫持：不符合就是"你不是真正的强者" |
| 所谓的 X，不过是 Y | 「所谓的稳定，不过是温水煮青蛙」 | 解构式抬杠，制造恐慌 |
| X 的尽头是 Y | 「打工的尽头是创业」 | 简单归因话术 |
| 记住，XXX | 「记住，没有人会教你赚钱」 | 命令式灌输，绕过你的思考 |
| 层次越高的人，越 X | 「层次越高的人，越不合群」 | 身份讨好 + 比较焦虑 |
| X%，的人都 Y | 「90% 的人都输在这一步」 | 伪造统计数字 |

### 2.2 震惊体与悬念钩子（标题党标准件）
| 句式 | 示例 |
|---|---|
| 震惊体 | 「震惊！XXX 竟然……」 |
| 人数隔离 | 「99% 的人都不知道」「只有 1% 的人看懂了」 |
| 后悔体 | 「不看后悔十年」「现在知道还不晚」 |
| 惊吓体 | 「看完惊出一身冷汗」「细思极恐」 |
| 时限体 | 「删前速看」「再不知道就晚了」 |
| 秘密体 | 「内行人绝不会告诉你的秘密」 |
| 提问体 | 「为什么你越努力越穷？」——预设了"你穷"的前提 |

### 2.3 身份绑架与比较句式
- 「你还 XX 岁吗？那你必须知道……」
- 「比你优秀的人，比你更努力」
- 「你的同龄人，正在抛弃你」
- 「爸妈不懂这些，孩子就输在起跑线」
- 「见过世面的女人/男人，都……」

### 2.4 AI 批量生产的文本指纹
这些特征说明内容大概率是 AI 生成 + 营销框架：
1. **排比堆砌**：连续 3 个以上结构相同的短句（「强者 X，智者 Y，仁者 Z」）。
2. **金句密度超标**：每 10 秒一个"可截图转发"的句子，但无实例、无数据、无推导。
3. **泛化主语**：通篇「你」「普通人」「聪明人」，没有任何具体人物、时间、地点。
4. **无出处的精确数字**：「调查发现，78% 的成功人士都……」——没有调查名称和样本量。
5. **万能结尾**：「关注我，带你XXX」「评论区扣 1，领取 XXX」。

## 第三章 结构套路库（叙事模板）

单条视频往往按固定模板拼装。识别模板比识别单个词更有效。

### 套路 S1：焦虑-解药结构（最常见）
> 反常识断言（制造恐慌）→ 名人/古书背书（借权威）→ 虚构案例（强化可信）→ 「3 个技巧」（给廉价解药）→ 「关注我领资料」（收网）。

### 套路 S2：禁书揭秘结构
> 「这本书被禁了 300 年」→ 引用一两条语焉不详的"原文" → 用现代成功学重新解读 → 「看懂的人都不简单」→ 引流卖书/卖课。

### 套路 S3：逆袭故事结构
> 「我以前负债 XX 万」→ 遇到贵人/学到某个思维 → 三个月翻身上岸 → 「现在我把方法总结成 X 节课」→ 私信/橱窗。**故事越戏剧化，越可能是编的。**

### 套路 S4：伪科普带货结构
> 「哈佛研究发现……」→ 某成分/习惯被神化 → 「但大多数人都做错了」→ 带货链接或团购。伪科普是健康、母婴赛道的重灾区。

### 套路 S5：情绪对立结构
> 选取性别、贫富、代际、地域的对立话题 → 极端化表达激化情绪 → 评论区吵架 → 算法判定"高互动"加大推荐 → 博主靠流量卖广告。**它的目的不是说服你，是激怒你。**

### 套路 S6：知识幻觉结构
> 用 60 秒讲《君主论》《国富论》→ 你产生"我学到了"的爽感 → 「完整版 20 节课」→ 收割认知焦虑。**判断标准：60 秒讲不完的书，60 秒更学不会。**

### 收网动作清单（出现即几乎 100% 是营销号）
- 「关注我，下期更精彩」「点个赞不迷路」
- 「评论区扣 1 / 扣 666，领取……」
- 「私信我 / 主页橱窗 / 左下角链接」
- 「限时优惠 / 仅剩 XX 名 / 今晚 8 点直播间」
- 「我已经帮 1000+ 学员上岸，案例在合集里」

## 第四章 逻辑谬误库（营销话术的底层引擎）

这些谬误是这类文案"听起来有道理"的根本原因。逐一对照，可逐条拆穿。

### 4.1 诉诸权威（Argument from Authority）——伪造或误用权威
- **话术形态**：「哈佛研究表明」「犹太人智慧」「稻盛和夫说过」。
- **拆穿方法**：追问三件事——**谁的研究？发表在哪？原文说过吗？** 90% 查无出处；剩下 10% 多为断章取义。
- **实例**：「脑科学证实：早起的人更成功」——真实研究只表明早起者与作息健康相关，与成功无因果。

### 4.2 幸存者偏差（Survivorship Bias）
- **话术形态**：「巴菲特每天 5 点起床，所以早起使人成功」「辍学的比尔·盖茨都成功了」。
- **拆穿方法**：问「**没做到的人有多少？他们去哪了？**」你只看到了金字塔顶端的 1 个人，没看到 100 万个同样作息却没成功的人。

### 4.3 虚假两难（False Dilemma / 非黑即白）
- **话术形态**：「穷人思维 vs 富人思维」「你不是老实人，就是被拿捏的人」。
- **拆穿方法**：世界是光谱不是二选一。「穷人思维」这个词本身就是把复杂的社会经济问题压缩成道德指责。

### 4.4 滑坡谬误（Slippery Slope）
- **话术形态**：「你现在不学 AI → 3 年后被淘汰 → 40 岁失业 → 一辈子完了」。
- **拆穿方法**：每一环"必然发生"都缺乏论证，恐惧被连续放大。真实世界有大量缓冲与分支。

### 4.5 以偏概全（Hasty Generalization）
- **话术形态**：「我认识的年薪百万的人，都……」「浙江人都会做生意」。
- **拆穿方法**：样本量是多少？是随机样本还是刻意挑选的样本？

### 4.6 虚假因果（Post hoc / 相关≠因果）
- **话术形态**：「成功人士都穿灰色西装 → 穿灰西装能成功」「喝咖啡的人更长寿 → 喝咖啡延寿」。
- **拆穿方法**：可能存在第三变量（有钱→穿好西装，也更长寿）。**顺序先后不等于因果。**

### 4.7 诉诸恐惧与紧迫（Appeal to Fear / Urgency）
- **话术形态**：「再不学就晚了」「最后 3 个名额」「你的孩子已经输在起跑线」。
- **拆穿方法**：**紧迫感和内容质量成反比。** 真有价值的知识不怕你回家想三天。制造稀缺是为了关闭你的理性判断窗口。

### 4.8 轶事证据（Anecdotal Evidence）
- **话术形态**：「我有个学员，照做之后月入 10 万」「我们家孩子吃了 XX 成绩明显变好」。
- **拆穿方法**：个例无法证明规律，且个例可以 100% 编造。要求看**可验证的统计数据**。

### 4.9 循环论证（Circular Reasoning）
- **话术形态**：「为什么他能成功？因为他有强者思维。什么是强者思维？成功者的思维就是强者思维。」
- **拆穿方法**：把结论当成论据，等于什么都没解释。

### 4.10 稻草人谬误（Straw Man）
- **话术形态**：「有人说读书没用——这些人根本不懂知识的复利效应」。
- **拆穿方法**：先把对方观点歪曲成弱化版本，再轻松反驳。遇到「有人说……」开头要警惕：**这个"有人"通常不存在**。

### 4.11 诉诸结果（Outcome Bias）
- **话术形态**：「他赌赢了，说明他的判断是对的」「公司上市了，证明这套管理方法有效」。
- **拆穿方法**：坏决策可能有好结果，好决策可能有坏结果。**用结果倒推方法正确性是赌徒逻辑。**

### 4.12 诉诸传统 / 神秘化（Appeal to Tradition / Mystery）
- **话术形态**：「老祖宗几千年就懂了」「天机不可泄露，我只说三分」。
- **拆穿方法**：流传久 ≠ 正确（放血疗法流传 2000 年）。**故意留三分"天机"，是为了让你买剩下的七分。**

### 4.13 身份定义劫持（No True Scotsman）
- **话术形态**：「真正的强者不抱怨」「你不是不行，是认知没到」。
- **拆穿方法**：任何反例都能被"真正的/合格的 XX"这个词挡回去，命题变得永远不可证伪——**不可证伪的话术就是话术。**

### 4.14 赌徒谬误与命运叙事
- **话术形态**：「你已经连续倒霉三次，运气该轮到你了」「2026 年是你的转运年」。
- **拆穿方法**：独立事件没有"轮到"一说；贩卖命运预测的下一步必然是付费改命服务。

## 第五章 过滤与标记判定系统（工具规则设计）

### 5.1 命中记分模型

每条被检测文本/字幕按如下方式记分：

```
总分 = Σ(命中词权重) + 套路结构加分 + 收网动作加权
```

| 信号类型 | 记分 |
|---|---|
| 五星词（★★★★★）命中 1 个 | +2 分 |
| 四星词命中 1 个 | +1 分 |
| 伪深刻句式命中 1 个 | +1 分 |
| 震惊体标题命中 1 个 | +2 分 |
| 收网动作命中（扣1/私信/橱窗/直播间） | +4 分 |
| 命中任一逻辑谬误关键词组合 | +2 分 |
| AI 文本指纹（排比≥3、金句密度、伪数字）命中 | +1 分/项 |

### 5.2 标记阈值（四级警报）

| 等级 | 分数 | 屏幕提示建议 |
|---|---|---|
| 🟢 正常 | < 5 分 | 不提示 |
| 🟡 疑似 | 5–9 分 | 边缘小字：「疑似营销内容」 |
| 🟠 高度可疑 | 10–15 分 | 提示 + 命中词高亮：「检测到 N 个营销特征：xxx」 |
| 🔴 确认收割 | > 15 分 或命中任一收网动作 | 醒目横幅：「营销收网动作，注意核实来源 / 不要付费」 |

### 5.3 降噪策略（避免误伤）
- 白名单豁免：正规媒体、学术论文链接、官方账号。
- 语境豁免：新闻、时事报道类可关闭"震惊体"计分。
- 反讽豁免：包含「营销话术盘点」等自我指涉词汇时不计分。
- 用户可调阈值：学习类用户可调低，普通用户用默认。

### 5.4 实现形态对比（供后续工具选型参考）

| 方案 | 平台 | 能力 | 限制 |
|---|---|---|---|
| 浏览器扩展 | 手机/桌面浏览器 | 分析网页文本、标题，注入警示条 | 无法覆盖 App 内内容 |
| Android 无障碍服务应用 | Android 全局 | 读取屏幕文本（含短视频字幕）→ 悬浮提示 | 需授予无障碍权限；视频画面文字需 OCR |
| iOS 快捷指令/无法全局 | iOS | 有限，只能做剪贴板检测、链接检查 | iOS 权限封闭，无法全局监控 |
| 剪贴板/分享检测 | 双平台 | 分享文本到工具 → 返回分析报告 | 只能被动检测 |

> 建议路线：**Android 优先做无障碍服务方案（全局实时标记），iOS 退化为分享检测 + 浏览器扩展**。

## 附：一句话自检口诀

> **标题越绝对，内容越空洞；紧迫感越强，套路越深；名词越玄乎，钱包越危险。**
> 看到任何「不学的你就完了」式内容，先问三个问题：
> **① 数据哪里来？② 他是谁、凭什么懂？③ 最后一句话是不是要你花钱？**
